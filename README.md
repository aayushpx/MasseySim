# MasseySim

MasseySim is a short university-life game set at Massey University. Explore campus, make choices, survive student life, and take on a range of quizzes and minigames along the way.

The game is currently available to play on itch.io:

**[Play MasseySim](https://mvmaiya.itch.io/masseysim)**

Built with Godot 4.
